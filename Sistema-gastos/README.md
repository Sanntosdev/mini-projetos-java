# 💰 Sistema de Gastos

Um pequeno sistema desenvolvido em Java para registrar e acompanhar gastos pessoais.

## Funcionalidades

* Adicionar gastos informando descrição, valor e categoria
* Listar os gastos cadastrados
* Calcular o valor total dos gastos

## Conceitos praticados

* Programação Orientada a Objetos (POO)
* Classes e objetos
* Encapsulamento
* Getters e setters
* Arrays de objetos
* Construtores
* Passagem de objetos e arrays entre classes
* Estruturas de repetição e decisão
* `Scanner` para entrada de dados
* Formatação de valores com `printf`

## Tecnologias utilizadas

* Java
* IntelliJ IDEA

## Sobre o projeto

Este projeto foi desenvolvido como um mini projeto de estudo para praticar Java e colocar em prática conceitos de Programação Orientada a Objetos.

A ideia foi criar uma aplicação simples, mas funcional, para registrar gastos e calcular o total gasto.
